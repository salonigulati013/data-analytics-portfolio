# E-Commerce Sales Dashboard

**Tool:** Microsoft Excel  
**Project Type:** Sales Analysis & Dashboard

## 📌 Objective

The objective of this project was to analyze e-commerce sales data and create an interactive Excel dashboard to understand sales performance, 
salesperson performance, company performance, and sales trends.

## 📊 Dashboard KPIs

- **Total Sales:** $26,914
- **Total Orders:** 34

## 🔎 Analysis Included

- Sales by salesperson
- Sales by company
- Daily sales trends
- Monthly sales trends
- Total sales and order count
- Regional/company-level analysis using filters

## 💡 Key Insights

- Margaret Peacock generated the highest salesperson sales at **$10,164**.
- Lifeline Health Centre had the highest company-level sales at **$10,014**.
- Thursday recorded the highest daily sales at **$8,880**.
- January recorded the highest monthly sales at **$12,814**.

## 🛠️ Excel Skills Used

- Data cleaning and preparation
- Excel formulas
- Pivot Tables
- Pivot Charts
- Slicers/filters
- GETPIVOTDATA
- Data aggregation
- Data visualization
- Dashboard design
