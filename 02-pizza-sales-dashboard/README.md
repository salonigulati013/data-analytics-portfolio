# 🍕 Pizza Sales Dashboard

An end-to-end pizza sales analysis project using **Excel and SQL** to analyze sales performance, customer ordering patterns, product performance, and key business KPIs.

The dashboard was created in **Excel**, and the key results were independently **validated using SQL queries** to ensure the calculations and insights were accurate.

---

## 📊 Project Overview

The goal of this project was to analyze pizza sales data and turn raw data into meaningful business insights through data cleaning, analysis, KPI calculations, visualization, and SQL validation.

### Key Questions Explored

* How much revenue did the business generate?
* How many orders and pizzas were sold?
* What is the average order value?
* Which pizza categories and sizes generate the most sales?
* Which pizzas are the best and worst performers?
* How do sales change throughout the day, week, and month?
* Which products contribute the most to overall revenue and sales volume?
