# Superstore Sales & Profit Analysis Dashboard

## 📊 Project Overview

This project analyzes Superstore sales, profitability, customer segments, product categories, regional performance, and returned orders using Power BI.

The dashboard was designed to provide an interactive view of overall business performance and help identify trends and areas affecting sales and profitability.

## 🎯 Key Objectives

- Analyze overall sales and profit performance
- Track sales and profit trends over time
- Compare performance across regions, categories, and customer segments
- Identify profitable and less profitable product categories and sub-categories
- Analyze profit margins
- Monitor returned orders and return rate
- Create an interactive dashboard using Power BI slicers

## 📌 KPIs

- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Return Rate

## 🔍 Analysis Included

- Sales & Profit Trend
- Sales by Region
- Sales by Category
- Sales by Sub-Category
- Sales by Segment
- Profit by Category
- Profit by Sub-Category
- Profit Margin by Category
- Returned Orders by Category

## 🛠️ Tools & Skills Used

- Power BI
- DAX
- Data Visualization
- Data Modeling
- Interactive Dashboards
- Excel

### DAX Measures

- `SUM`
- `DISTINCTCOUNT`
- `DIVIDE`

## 📈 Dashboard Features

- Interactive Year, Region, Segment, and Category slicers
- KPI cards for key business metrics
- Multiple visualizations for sales and profitability analysis
- Category and sub-category level analysis
- Return analysis
- Interactive filtering across the dashboard
